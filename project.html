Project

Projects Developed at HCMUTE by Ngocat.

Student projects focused on system programming, IoT, AI, and microelectronics, developed during studies at HCMUTE.

FPGA

  • 09/2025 - Now – RISC-V 32I Instruction Set Implementation on FPGA

    • Design and test basic RISC-V 32I instructions (arithmetic, logic, load/store, branch) using Verilog on Spartan-3E. The processor core is synthesized and verified through simulation and FPGA deployment.

  • 02/2024 - 05/2024 – Traffic Light Controller in Verilog

    • Developed and tested a traffic light circuit using integrated circuit design principles. Designed and implemented a finite state machine (FSM) to control the traffic light system. Collaborated with team members to optimize circuit performance and document project findings in a technical report.

IOT

  • 03/2025 - 06/2025 – Automatic Awning System

    • An IoT-based automatic awning system built with ESP32 and Firebase. The system allows users to remotely control and monitor the awning via a web interface. It supports real-time status updates, remote open/close commands, and weather-based automation using sensors. Firebase is used for data storage, user authentication, and cloud synchronization.

  • 10/2022 - 1/2023 – Line-Following and Obstacle-Avoiding Robot

    • An Arduino-based robot designed to follow a line and avoid obstacles using infrared sensors and a sound sensor. The IR sensors detect the path, while the sound sensor enables basic interaction or control. The system combines real-time sensor input with motor control to navigate autonomously.

Sram

  • 09/2024 - 12/2024 – 6T SRAM Array (4×4 Configuration) Design and Simulation

    • Design and implement SRAM memory cells for stable and efficient data retention. Integrated essential circuit components, including pre-charging circuits, write cells, sensor amplifiers and decoder 2 to 4. Simulated and optimized the 4×4 SRAM array, evaluating power consumption and propagation delay

AI

  • 01/2025 - 04/2025 – Fiftyone and manger data

    • Used FiftyOne to manage and visualize a medical image dataset for classifying healthy vs. diseased cells. The project involved labeling, filtering, and evaluating model predictions to support cell-level diagnosis.
